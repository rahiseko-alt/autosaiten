# ひな型専用フォルダ

このフォルダは、ひな型（rahiseko-alt/MATT2）自身を改良するための記録置き場です。
ひな型から新しい案件を複製すると、最初の会話で片づけ役（`.claude/hooks/template-cleanup.sh`）が
このフォルダごと消し、引き継ぎメモを白紙に戻します。

- `origin`: ひな型の名前（持ち主/名前）。送信先がこれと違えば「複製先」と判定する。
  ひな型の置き場所の名前を変えたら、ここも必ず書き換える（書き換え忘れると、ひな型自身が片づけられる）
- `handover-seed.md`: 複製先の引き継ぎメモに入れる最初の1件
- `CONTEXT.md`: ひな型自身の用語集
- `docs/adr/`: ひな型自身の決めた理由

複製先の用語集（ルートの `CONTEXT.md`）と決めた理由（ルートの `docs/adr/`）は、
複製先の案件のためのものです。ひな型の記録はそこに混ぜません。
