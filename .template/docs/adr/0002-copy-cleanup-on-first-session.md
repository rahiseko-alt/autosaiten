# 複製先の作業日誌は、最初の会話で片づけ役が自動で消す

GitHub のひな型機能は全ファイルをそのまま写し、除外の設定が無い。そのため、ひな型自身の作業日誌が複製先に写り、最初の会話で「前回の続きはひな型の改良です」と誤案内が出ていた。ひな型専用の記録を1つのフォルダにまとめ、会話開始時に送信先の名前とひな型の名前を比べて、複製先ならそのフォルダと保管庫を消し、引き継ぎメモを白紙に戻す。利用者が手で消す方式は、消し忘れで同じ誤案内が起きるため採らなかった。

## Consequences

- ひな型の置き場所の名前を変えたら `.template/origin` も書き換える必要がある。書き換え忘れると、ひな型自身が「複製先」と判定されて片づけられる。
