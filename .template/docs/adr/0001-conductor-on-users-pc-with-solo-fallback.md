# 指揮役は利用者のパソコンに置き、使えないときは単独モードで続ける

利用者の契約は3社とも月額プランで、他社の道具（Codex・Gemini）へのログインにはブラウザでのコード入力が要る。遠隔の作業環境は会話ごとに消えるため、そこを指揮役にすると毎回ログインが必要になり、「人が関わるのは3回だけ」と両立しない。そこで指揮役は利用者の Windows パソコンに置き、外出先からはスマホで遠隔操作する。パソコンが使えないときは、作業を止めずに Claude が全役割を代行し（単独モード）、他社による確認は後回しの確認として記録して次の自動モードでまとめて行う。

## Considered Options

- 遠隔の作業環境で、ログイン情報を秘密の設定に保存して持ち込む: ログイン情報が自動更新で古くなる恐れと、月額プランの規約上の可否が未確認のため見送り。
- パソコンが使えないときは人に道具の切り替えを案内して待つ: 人の手が空くまで止まり、開発が遅れるため見送り。
