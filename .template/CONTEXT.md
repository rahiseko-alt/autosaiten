# ひな型（開発の段取り）

非エンジニアの利用者が、複数社の AI の道具を使い分けて開発を進めるための段取り一式。製品のコードは含まない。

## 人と役割

**利用者**:
段取りを使って開発を進める人。関わるのは人の確認点だけ。
_Avoid_: ユーザー、オーナー

**指揮役**:
利用者のパソコン上で段取りを進め、各段階の仕事を担当に振る Claude Code。
_Avoid_: オーケストレーター、司令塔

**担当**:
ある役割の仕事を実際にこなす、道具とモデルの組み合わせ（例: Codex の GPT-6.1 Sol）。
_Avoid_: ワーカー、エージェント

**役割**:
段取りの中の仕事の種類（設計、設計の確認、実装・軽い作業など）。1つの役割に担当の候補が優先順で並ぶ。

**役割表**:
役割ごとの担当の候補を優先順に並べた表。モデルの乗り換えはこの表の書き換えだけで行う。
_Avoid_: 設定ファイル、モデル表

**代わりの担当**:
役割表で2番目以降に並ぶ担当。前の担当が使えないときに回される。
_Avoid_: フォールバック

**振り分け役**:
役割名と依頼文を受け取り、役割表から使える担当を選んで仕事をさせる部品。
_Avoid_: ルーター、ディスパッチャ

## 動き方

**自動モード**:
他社の道具が使え、役割表どおりに3社へ仕事を振れる状態。

**単独モード**:
他社の道具が使えず、Claude が全役割を代行して作業を続ける状態。
_Avoid_: 手動モード、縮退モード

**後回しの確認**:
単独モードで Claude が代行した「他社による確認」。作業指示として記録し、次の自動モードでまとめて行う。

**人の確認点**:
利用者が関わる3つの時点。最初の相談、途中確認（最初に「動くもの」ができた時点）、最終確認。
_Avoid_: 承認ゲート、レビュー

## ひな型と複製先

**ひな型**:
新しい案件を複製する元の置き場所。rahiseko-alt/MATT2。
_Avoid_: テンプレート（会話では同義として許容）

**複製先**:
ひな型から作った新しい案件の置き場所。

**ひな型専用フォルダ**:
ひな型自身の記録だけを入れるフォルダ。複製先では最初の会話で消える。

**片づけ役**:
会話開始時に、複製先ならひな型専用フォルダを消し引き継ぎメモを白紙に戻す部品。
