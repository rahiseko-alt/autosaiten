# 先生が触るのは「試験作成」シート1枚にし、裏方のシートへは「これでOK」のときに写す

17列の Questions、Control、Settings、Rubrics に分かれた入力は、先生には使いにくかった。そこで、先生が触るシートを1枚にまとめ、列を9つ（掲載・問題文・種類・配点・正答・別解・選択肢・採点の観点・必須）に減らし、採点方式は「種類」から決める。裏方のシートとの対応は数式ではなく、「これでOK」のときに台本が写す。数式は、チェックボックスや固定の問題番号を扱うと壊れやすいためである。問題番号は表の右端に自動で付け、行と一緒に動くので、並べ替えても過去の結果との対応は崩れない。設計書 §6〜§8 のシート構成は、裏方としてそのまま残す。
