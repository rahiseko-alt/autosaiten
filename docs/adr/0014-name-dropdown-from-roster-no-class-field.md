# 氏名は名簿から選ぶプルダウンにし、クラス欄はなくす

氏名の手入力は表記ゆれ（全角と半角のスペースなど）で名簿と合わず、授業外の判定が「要確認」で止まる。そこで名簿があるテストでは、氏名欄を名簿の氏名そのままのプルダウンにし、クラス欄はなくす。クラスは名簿の氏名から決まるので、授業外の判定（ADR 0013）は、回答のクラスが空のときは「選んだクラスとの突き合わせ」をせず、名簿で氏名から引いたクラスだけで行う（クラスが入っている従来の回答は、従来どおり突き合わせる）。名簿が空のテストは、今までどおり手入力の氏名欄にする。

選択肢は名簿の氏名のみ、名簿の順にする（学生番号は付けない）。名簿に学生を足したときは「これでOK」を押し直すだけで選択肢を直し、新しい版は作らず、回答は消えない（選択肢の中身は定義の指紋に入れない。クラス欄の選択肢は指紋に入っており、今回は変えない）。名簿が空から埋まる、または空になると氏名欄の形が変わるので、回答があれば新しい版を作る（ADR 0002）。名簿にない人のための「その他」は作らない（手入力の表記ゆれが戻るため）。名簿に同じ氏名が2人以上いるときは、「これでOK」を押した時点で止めて、名簿を直してもらう。

## Considered Options

- クラスごとにプルダウンを分ける: 授業外の判定は名簿のクラスで足りるので、学生の入力が増えるだけで利点がない。
- 氏名の再入力（署名）欄を足して突き合わせる: 満点でない人に赤い✕が付く問題（ADR 0013）の再来になり、先生が取りやめた。
- アドレスと名簿のアカウントの照合: 名簿のアカウント欄が埋まってから、後日行う（ADR 0010 の照合の強化）。

## Consequences

- すでに作成済みのテストには反映しない。ひな型を直したあとに作るテストから使う（ADR 0010）。
- フォームの回答のクラス（respondent_class）は空になる。取り込みはそのまま動き、授業外の判定は名簿のクラスを使う。
- 他人の氏名を選べてしまう。後日の名簿のアカウントとの照合で補う。
