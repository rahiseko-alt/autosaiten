# テストは1回ごとに別のスプレッドシートにし、全テスト共通の集計表が結果を吸い上げる

3科目で半年に約15回のテストを作る。今の仕組みは1つのスプレッドシートが1つのテストだけを扱う作り（現在のフォームの記録が1つ、Results にテストを区別する列が無い）なので、1つのスプレッドシートにまとめると Results の作りを大きく変えることになる。そこで、テストは1回ごとにひな型をコピーして作る。集計は全科目・全テスト共通の1つの集計表で行う。集計表の側から各テストの Results を吸い上げ、テスト側からは送らない。テスト側の表の列は変えずに済み、集計の作りを変えてもテストに手が入らない。

正しい名簿（氏名・クラス・アカウント・別のアカウント・別の綴り）は集計表に置き、新しいテストを作るときに写す。学生の照合はアカウントと氏名の両方で行う。アカウントは主な手がかりだが、学生が別のアカウントで回答することがあり、そのときは氏名で追う。照合できないものと2回送信は「要確認」として先生が決め、直した結果は名簿に残す。

## Consequences

- テストのスプレッドシートは、コピーした時点の仕組みに固定される。仕組みを直したときは、ひな型を更新すれば次のテストから反映される。保管したテストは後から変わらない。
- 1分ごとの自動処理は、実施中のテストだけで動かす。返却が終わったテストは「保管する」で自動処理を止め、フォームを閉じ、保管用のフォルダへ移す。採点の確定や集計表への取り込みが残っていれば、保管しない。
