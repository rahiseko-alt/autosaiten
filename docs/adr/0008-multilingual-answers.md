# 学生の回答は多言語で来る前提で採点する

学生は多国籍で、回答は日本語に限らない。問題文は日本語のままでよいが、採点はどの言語の回答にも対応する。ルールでの採点（短答・数値）は、正答と一致すれば即座に満点とし、一致しない回答は「別の言語で正しく答えている」可能性があるため、0点で確定させず要確認にして、Claude が意味で判定する。数値は、各国の数字（アラビア数字以外の十進数字）を半角に直し、数として読めて許容差の外なら不正解で確定する。正規化は、NFKC に加えて、全言語の大文字小文字をそろえ、ラテン文字のアクセント記号を外す（日本語の濁点・半濁点は外さない）。選択式は選択肢が決まっているので、これまでどおりフォームの自動採点とする。記述は、回答の言語にかかわらず内容で採点し、ルーブリックに無い限り言語や文法で減点しない。採点の理由は先生が読めるよう日本語で書く。
