# 学生の回答は多言語で来る前提で採点する

学生は多国籍で、回答は日本語に限らない。問題文は日本語のままでよいが、採点はどの言語の回答にも対応する。ルールでの採点（短答・数値）は、正答と一致すれば即座に満点とする。一致しない回答のうち、正答・別解に無い種類の文字（英字・ハングル・キリル文字など。日本語は漢字・ひらがな・カタカナをまとめて1種類）で書かれたものだけ、別の言語で正しく答えている可能性があるため要確認にして、Claude が意味で判定する。正答と同じ種類の文字の誤答は0点で確定する（不正解をすべて Claude に回すのは利用者が退けた）。そのため簡体字の「东京」のように同じ種類の文字で書かれた別言語の正答は、先生が別解に書かない限り0点になる。数値は、各国の数字（アラビア数字以外の十進数字）を半角に直し、数として読めて許容差の外なら不正解で確定する。数として読めない回答は、日本語以外の文字で書かれた場合（twenty-five など）だけ要確認にする。正規化は、NFKC に加えて、全言語の大文字小文字をそろえ、ラテン文字のアクセント記号を外す（日本語の濁点・半濁点は外さない）。選択式は選択肢が決まっているので、これまでどおりフォームの自動採点とする。記述は、回答の言語にかかわらず内容で採点し、ルーブリックに無い限り言語や文法で減点しない。採点の理由は先生が読めるよう日本語で書く。

「選択式はフォームの自動採点」の部分は ADR 0013 で置き換えた（仕組みの中で正答と比べて採点する）。
