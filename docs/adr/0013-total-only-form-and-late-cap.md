# フォームには合計点だけを出し、授業外の提出は先生が決めた上限点までに抑える

先生は、フォームでは合計点を1か所にだけ出し、内訳は講評で伝えると決めた。そこで、問題の項目には点数を付けず（選択肢の正解も設定しない）、採点はすべて仕組みの中で行う。合計点の受け皿には氏名欄を使う。必須の欄で必ず回答があり、回答の無い項目には点を書き込めないためである。確定した回答の書き戻しでは、氏名欄に合計点と講評の全文を書き込む。

授業時間外の提出は、人に聞いてよい決まりなので、授業内の提出と差を付ける。4点の加点はやめ、授業外の提出の合計点を、先生がテストごとに決めた上限点までに抑える（空欄なら抑えない）。抑えた分は、Results に問題番号 `__LATE__` の行（最終点は負の数）として残す。Results の最終点を足せば抑えた後の合計点になるので、集計表は足すだけで済み、同じ計算を2か所に持たずに済む。授業内か授業外かは、学生が選んだクラスではなく、テストに写した名簿のクラスで判断する。食い違うときや判断できないときは要確認にし、先生がその行の manual_score で決める。

この決定は、ADR 0003 の「選択式の標準採点はフォームが即時に行う」と、ADR 0008 の「選択式はフォームの自動採点とする」と、ADR 0011 の「問題ごとの点数をフォームの回答に書き込む」を置き換える。

## Consequences

- 成績の公開の設定（送信直後／後で手動）は Apps Script から変えられないため、先生がフォームごとに「後で手動で公開」にする。
- `__LATE__` の行は、確定のたびに作り直す（上限点や終わる日時を直して「手動採点を反映」を押し直せば直る）。
