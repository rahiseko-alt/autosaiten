# 受付ページは名簿から名前を選ぶ方式にし、採点の仕組みとは別の Apps Script プロジェクトにする

学生ごとに数字違いの資料を配るため、学生が最初に開く受付ページを作る。見分け方はメールアドレスではなく、クラスと名簿の名前を選ぶ方式にした。教師のアカウントは学校用ではない Gmail で、「作成者として実行」のウェブアプリは開いた人のメールアドレスを受け取れない。受け取るには「アクセスした人として実行」にして学生一人ひとりに未確認アプリの警告画面を通らせる必要があり、授業中の60人には現実的でなかった。名前の手入力は表記ゆれで同じ人が別人になるため、名簿から選ばせる。他人の名前を選べば他人の資料が見えるが、授業中の監督で対応できる範囲として受け入れた。

受付ページは採点の仕組み（`src/`）と別のプロジェクト（`reception/`）にした。誰でも開けるウェブアプリでは、末尾が `_` でない関数はすべて画面から呼べるので、同じプロジェクトに置くと、Results の読み出しやフォームの新版作成まで外から実行されうる。関数ごとに本人確認を入れる案は、時間主導のトリガーで本人を確かめられる保証が無く、補助関数まで守りきれないため採らなかった。

名簿・資料シートは先生（と Claude）が埋める入力だが、ADR 0007 の「先生が触るのは試験作成シート1枚」は問題の作成についての決めであり、受付ページのための名簿と資料はその例外として扱う。
