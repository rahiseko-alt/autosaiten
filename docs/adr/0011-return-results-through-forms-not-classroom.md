# 結果は Google フォームで返し、Classroom には入れない

学生へは、問題ごとの点数と講評をフォームの回答に書き込み、先生が「成績を公開」して返す。講評は Results の採点の理由の欄に、学生が読む前提で普通の日本語で書く（列は増やさない）。Classroom の API は、その仕組み自身が作った課題にしか点数を書き込めず、講評を書き込む方法も見当たらなかった。先生も Classroom の成績表は要らないとした。フォームの成績は本人にしか届かないが、「回答の概要を表示する」をオンにすると他の学生の回答が見えるため、仕組みの側で常にオフにする。フォームから成績を届けるには回答者のアカウントが要るので、アカウントを集めるのを初期設定にした。
