# Windows での初回準備

パソコンの前で、上から順にこなすだけで終わる手順です。所要時間の目安は30分です。
終わると、外出先からスマホで指示するだけで、Claude・GPT（Codex）・Gemini の3社の道具に仕事を振り分けて
開発が進むようになります。

この準備は**パソコン1台につき1回だけ**です。案件ごとにやり直すのは「4. 案件を手元に用意する」と
「5. スマホから操作できるようにする」だけです。

> 【曖昧】このひな型の作者は、Windows 上で Codex と Gemini の道具がそのまま動くことをまだ確かめていません。
> 「3. 3社にログインする」で動かなかった場合は、その画面の写真を Claude に見せて相談してください。
> 動かない道具があっても、その会社の分は Claude が代わりに担当するので、開発は止まりません。

## 1. 下準備の道具を入れる

1. **Git for Windows** を入れる: https://git-scm.com/downloads/win を開き、案内どおりに入れる（設定は全部そのままで構いません）。
   Claude Code は、これに含まれる「Git Bash」を使って動きます。
2. **Node.js（LTS と書かれた方）** を入れる: https://nodejs.org/ を開き、案内どおりに入れる。
   Codex と Gemini の道具は、これを使って入れます。

入れ終わったら、スタートメニューから **「Git Bash」** を開きます。以降のコマンドはすべてこの画面に貼り付けて Enter を押します。

## 2. 3社の道具を入れる

```sh
npm install -g @anthropic-ai/claude-code @openai/codex @google/gemini-cli
```

終わったら、入ったことを確かめます。3行とも数字（版番号）が出れば成功です。

```sh
claude --version
codex --version
gemini --version
```

> 【曖昧】Claude Code は、公式の案内で別の入れ方（PowerShell から入れる方法）が勧められている場合があります。
> 上のコマンドで `claude --version` が動かないときは https://code.claude.com/docs を開き、Windows の入れ方に従ってください。

## 3. 3社にログインする

どれも一度だけです。ログイン状態はパソコンに残ります。

1. **Claude**: `claude` と打って開き、画面の案内どおりにブラウザで Claude にログインする。終わったら `/exit` で閉じる。
2. **GPT（Codex）**: 次を打つ。ブラウザが開くので、ChatGPT のアカウントでログインする。

   ```sh
   codex login
   ```

   ブラウザが開かないときは `codex login --device-auth` と打つ。表示された URL をブラウザで開き、
   表示された短いコードを入力する。
3. **Gemini**: `gemini` と打って開き、ログイン方法で **「Sign in with Google」** を選ぶ。
   ブラウザで Google アカウントにログインする。終わったら `/quit` で閉じる。

   ブラウザが自動で開かないとき、または画面に「Enter the authorization code」と出たときは、
   画面に出た長い URL をブラウザで開いてログインし、ブラウザに表示されたコードをコピーして、
   Git Bash の画面に貼り付けて Enter を押す（5分以内に行う）。

4. **動くかの確認**: 次を打つ。

   ```sh
   sh .claude/router/route.sh --check
   ```

   これは「4. 案件を手元に用意する」の後でないと打てないので、4. を済ませてから戻ってきて打つ。
   最後の行が `mode: auto` なら、Codex か Gemini の少なくとも一方が使える状態です。
   `codex: available` と `gemini: available` の両方が出れば、3社とも使えます。
   `not-installed` は「2. 3社の道具を入れる」を、`not-logged-in` は上のログインをやり直してください。
   それでも直らないときは、その画面の写真を Claude に見せて相談してください（その会社の分は Claude が
   代わりに担当するので、開発は止まりません）。

## 4. 案件を手元に用意する

案件（このひな型から複製したもの）ごとに1回行います。`<持ち主>/<名前>` は案件の名前に置き換えます。

```sh
cd ~
git clone https://github.com/<持ち主>/<名前>.git
cd <名前>
```

## 5. スマホから操作できるようにする

案件のフォルダ（4. で移動した場所）で、次を打ちます。

```sh
claude remote-control
```

スマホの Claude アプリの「Code」に、この会話が現れます。以降はスマホから指示できます。
**作業中はパソコンを起動したまま、この画面を閉じないでください。**（パソコンの省電力設定で
スリープしないようにしておくと安心です。）

## 6. 役割表のモデルが使えるか確かめる

最後に、スマホかパソコンの Claude に、次の一文をそのまま送ります。

```
初回準備の確認をして。sh .claude/router/route.sh --check を実行し、役割表（.claude/router/roles.txt）の担当を1つずつ短い依頼で試して、使えないモデルは同じ会社の使えるモデルに差し替えて記録して。
```

Claude が、3社の道具がそれぞれ使えるか（自動モードか単独モードか）を確かめます。続けて、役割表の各担当に
短い依頼を1回ずつ送り、月額プランで選べないモデルがあれば差し替えて記録します。
結果は「使えた担当／差し替えた担当」の一覧で報告されます。

これで準備は終わりです。あとは `/grill-with-docs` で作りたいものを相談し、`/conduct` で任せてください。
