## 2026-10-21 多言語の回答・氏名欄・1人1回に対応した

**決めたこと**

- 回答は多言語の前提で採点する（ADR 0008）。短答・数値の誤答は0点で確定し、正答と違う文字（別の言語）で書かれた回答だけ要確認にして Claude が意味で判定する。記述は言語にかかわらず内容で採点し、理由は日本語で書く
- フォーム先頭に必須の「氏名（Name）」欄。結果の回答者に出し、採点には使わない
- 回答は1人1回（学生は Google ログイン）。Settings の LIMIT_ONE_RESPONSE で外せる
- Q005 の解答（別の課題への解答）は 2/20点で採点済み。「手動採点を反映」は未実行

**次にやること**

- PR を取り込んでから、利用者のパソコンで新しい ZIP を展開し、`.clasp.json` を写して `clasp push`、そのあと「初期セットアップ」をやり直す（Results に respondent_name 列が足される）
- 「これでOK」を押すと、氏名欄入りの新しい版のフォームができる。新しいフォームURLを配る

**未解決の問題**

- 簡体字のように日本語と同じ漢字で書かれた別言語の正答は、別解に書かない限り0点になる

## 2026-10-21 先生が触るシートを「試験作成」1枚にまとめた

**決めたこと**

- 先生が触るのは「試験作成」（これでOK・状態・フォームURL・タイトル・問題の表9列）と「結果」の2枚だけ。ほかは裏方として隠す（ADR 0007）
- 列は 掲載・問題文・種類・配点・正答・別解・選択肢・採点の観点・必須。採点方式は種類から決め、問題番号は右端に自動で付く
- テストは Q005（在留手続のファクトチェック、20点・記述）の1問だけ。条件文は Google ドキュメント「Q005 資料（条件文とAIの説明）」に分けた

**次にやること**

- PR を取り込んでから、利用者のパソコンで新しい ZIP を展開し、古いフォルダの `.clasp.json` を写してから `clasp push`。そのあと「初期セットアップ」をやり直す（既存の Questions は試験作成へ自動で引っ越す）
- 資料のドキュメントを「リンクを知っている全員が閲覧可」にしてから、「これでOK」を押す

**未解決の問題**

- 隠した Results で行を選ぶ「選択回答を再採点」は、先生には使いにくい（Claude が代わりに行う運用で当面しのぐ）
- 行のコピーを元の行より上に貼ると、上のコピーが元の番号を取る
