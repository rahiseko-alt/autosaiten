- 手で足した行の氏名が名簿の表記（半角スペース）と合わないと、授業外の行が要確認で止まる
- Results の response_id を本物のIDにしないと、フォームへ点数を書き戻せない
- 学生側の「スコアを表示」、「成績の発表」「点数」の設定は、先生の確認結果をまだ聞いていない
