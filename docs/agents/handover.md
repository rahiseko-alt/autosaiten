## 2026-10-03 指揮役は利用者のパソコン、使えないときは手動で続行

**決めたこと**

- 指揮役（Claude Code）と他社の道具（Codex・Gemini）は利用者のパソコンで動かす。外出先からは
  スマホの Claude アプリで遠隔操作する。各社へのログインはパソコンで一度だけ行う
- パソコンが使えないときもある。その場合は道具・モデルの切り替えと関わる回数が人任せになるが、
  それで開発が止まったり遅れたりしない作りにする
- パソコンが使えないときは Claude だけで全役割を代行して進め続け、他社による確認は次にパソコンが
  使えるときにまとめて行う。どちらで動くかは作業の始めに指揮役が自分で判定し、一言伝える
- 複製先では引き継ぎメモを空から始め、ひな型自身の用語集・決めた理由は複製先に写らない形で置く
- 利用者のパソコンは Windows
- 複製先の最初の会話で、指揮役が「ひな型から作った新しい案件だ」と判定し、写ってきたひな型の
  作業日誌（引き継ぎメモ・ひな型自身の用語集や決めた理由）を自動で片づけて白紙から始める。
  そのためひな型専用の記録は1つのフォルダにまとめる
- 役割表の初期値: 設計=Claude Opus／設計の確認=GPT-6.1 Sol と Google の一般向け最上位モデル（別々に）／
  実装・軽=Gemini Flash／実装・複雑=GPT-6.1 Sol／仕上げの確認=Claude Opus と GPT-6.1 Sol（別々に）／
  修正=Flash か Sol、設計変更のみ Opus。Gemini 4 Argon は招待制のため外した
- 途中確認は、最初に「動くもの」が1つできた時点で行う
- 既存の段取り（相談→計画書→小分け→実装→確認）はそのまま使い、各段階の担当を役割表で決める
- 役割表には代わりの担当も書き、使用上限に達したら自動でそちらへ回す
- 最終確認で GO が出たら指揮役が自動で本流へ取り込む
- 途中確認・最終確認は、3行の説明と画面写真（作るものによっては触れる画面へのリンク）をスマホへ送る

**次にやること**

- 利用者が「認識が揃った」と確認したら `/to-spec` で計画書にする。用語集と決めた理由（指揮役を利用者のパソコンに
  置き、使えないときは Claude 単独で続ける件）は、ひな型専用フォルダができた時点でそこへ書く
- パソコンでの初回準備時に、各社の月額プランで役割表のモデルが選べるか確かめる

**未解決の問題**

- 月額プランのログイン情報を遠隔の作業環境に保存して使うことが規約上許されるかは未確認
